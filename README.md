# AI Docs-as-Code with MkDocs

Governed documentation workflow using Markdown, MkDocs Material, GitHub Actions, Vale, AI-assisted review, and human approval.

## Published documentation

https://harjotdhodi-gif.github.io/AI-Docs-as-Code-MKDocs/

## Automated outputs

The Docs CI/CD workflow builds and publishes:

- HTML documentation through GitHub Pages
- PDF downloads
- DOCX downloads

## Review controls

Pull requests run:

- Vale Documentation Review for deterministic style and terminology checks
- AI Documentation Review for contextual, consistency, security, and risk findings
- Docs CI/CD validation before publishing
