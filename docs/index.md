## How changes are handled

All documentation updates follow a **Docs-as-Code workflow**:

1. Create a branch and update Markdown files.
2. Open a Pull Request.
3. Run automated Vale, MkDocs, and AI documentation checks.
4. Let a human reviewer approve the final editorial and technical decision.
5. Merge the Pull Request to publish the approved site.

!!! tip
    Keep topics short and task-focused. Use meaningful headings, metadata, and tags so readers can scan and find information quickly.
