# Support Request Workflow

## Create a request

1. Sign in to the customer portal.
2. Open **Support requests**.
3. Select **Create request**.
4. Choose the category that best describes the issue.
5. Enter a concise subject and a clear description.
6. Attach approved supporting files when they are necessary.
7. Review the information and select **Submit**.

The portal assigns a request number after submission. Store this number for future reference.

## Track progress

Open the request to review its status, assigned team, comments, and requested actions. Add new information as a comment instead of creating a duplicate request for the same issue.

!!! tip "Useful descriptions"
    Include the affected product, the action you attempted, the result you expected, the result you received, and the approximate time of the problem. Remove passwords, access tokens, and unnecessary personal data before attaching files.

## Close the request

Confirm that the resolution addresses the reported issue. Add a final comment when clarification is required. Close the request only after the agreed validation is complete.
