# Documentation updates

Use this section for release notes, workflow changes, governance announcements, and major documentation improvements.

## What belongs here

Publish an update when a change affects how writers, reviewers, administrators, or readers use the documentation system. Examples include:

- New publishing formats or download options
- Changes to Vale or AI review controls
- Updated documentation governance requirements
- Major navigation or user-experience improvements
- New product, process, or compliance documentation

Each update should identify what changed, who is affected, when the change takes effect, and where readers can find the related guidance.
